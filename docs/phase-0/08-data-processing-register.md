# GaoQ-OS 数据处理活动登记册

- 文档编号：phase-0/08
- 状态：仓库实施基线；不代表法务、隐私、数据负责人或目标环境已经签署
- 适用范围：ERP、Web、Worker、迁移工具、外部集成、MCP 与发布证据
- 负责人：数据负责人维护，安全负责人复核控制，法务/隐私负责人批准依据与期限

本登记册落实领域与数据规范要求。表中的“依据”是系统设计所依赖的业务依据类别，
不是法律意见；上线前必须由适用法域的法务/隐私负责人确认具体条款、告知文本、
跨境结论和保留期限。未完成确认时，对应 Phase 保持 No-Go。

## 2. 共享与跨境边界

1. 默认部署与处理区域为中国境内私有 VPC。任何跨境传输、境外模型/搜索服务或
   新增处理区域必须单独完成 PIA、数据清单变更、法务批准和 ADR；未批准时失败关闭。
2. 钉钉、飞书、OP、e签、招聘渠道、银行、税务、通知、对象/WORM、搜索/评分、
   专业算薪等共享对象只接收字段映射表登记的最小值。Token、Secret 和上游正文
   不得作为共享数据。
3. 外部供应商更换、用途扩张、敏感级别变化、保留期缩短或新增接收方必须在同一
   PR 更新本登记册、适配器映射、运行时 schema、测试和对应 PIA/ADR。

## 3. 数据主体请求与保留期执行

- 身份核验、访问、更正、撤回、删除/匿名化请求必须由可信人员会话进入对应领域
  应用服务；AI/MCP 不得直接执行物理删除、密钥销毁、审计删除或死信重放。
- 删除不是单库操作：必须覆盖主库、索引、缓存、对象、下游系统和未来处理阻断；
  备份通过密钥销毁和备份到期实现，并保存不含个人原文的执行证明。
- 法定保留、争议冻结或不可变证据要求优先于普通删除，但必须记录依据、批准人、
  到期时间和后续处置；不得以“永久保留”作为默认值。
- 生产前由数据、法务/隐私、安全和业务负责人逐行签署本登记册。任何未签署活动
  都不能被 Phase 5 privacy-compliance verdict 或总 Go/No-Go 判为通过。
