# ADR-0007：业务运行时与联邦数据集

- 状态：accepted
- 日期：2026-08-10
- 关联 Issue：无（产品基础设施目标）
- 替代关系：无

## 背景

拖拽表单、多维表、审批和自动化需要成为 GaoQ OS 的共享基础设施，同时允许 OP
等专业系统的数据参与统一展示和流程。若把外部数据复制为动态记录，会形成双主、
权限漂移和无法证明审批时点事实；若各界面自行解释元数据，则字段、查询和流程语义
会持续分叉。

## 决策

GaoQ OS 建立版本化业务运行时，统一解释业务数据集、外部记录引用、字段投影和业务
证据快照。原生数据集由 GaoQ OS 拥有；OP、专业算薪等以外部数据集 Adapter 接入，
继续保持唯一事实源。多维表和表单只保存外部记录引用，实时展示通过权威应用服务
读取；审批与其他不可逆决定保存最小不可变快照。对外部系统的写入只能使用登记的
受控业务命令和可靠事件链，禁止动态运行时直接访问或修改外部数据库。

## 后果

- REST、MCP、CLI、表单、多维视图、审批和自动化必须复用同一运行时语义。
- 外部数据集必须声明字段、版本、查询能力、敏感等级和可执行命令；未声明能力失败关闭。
- 原生动态记录仍需建设类型化查询投影，不能以客户端有限扫描代替生产查询。
- 外部记录的实时值可以变化；需要证明当时决定的流程必须同时保存来源版本和证据快照。

## 已交付解释层（2026-08-10）

- `DatasetRef` 用 `kind + system/objectType/schemaVersion` 或
  `datasetId/schemaRevision` 标识 Schema，不把数据库集合名作为业务契约。
- `DatasetRuntimeService` 统一承载目录、精确查询、按版本解析和证据快照；REST、
  MCP、CLI、多维 Base 与表单设计器复用同一语义。
- 首个外部 Adapter 为 OP 经营摘要。Adapter 只复用 OP 应用服务并反向绑定请求、
  Schema 与返回记录；L3/L4 字段不进入通用投影。
- `dataset_reference` 表单字段只保存来源引用。提交审批时重新读取权威记录，并把
  来源 Schema、记录版本、观察时间、最小字段与内容摘要编译进不可变审批事实。
- Base 自动化使用持久运行账本和逐动作幂等键执行原生建记录、更新记录和发起审批。
  通知与 Connector/OP Command 在适配器未登记时进入 `manual_review`，不产生外部
  副作用。
- 生产新增 `base_automation_runs` 集合及只追加索引迁移 v2；代码交付不代表迁移、
  外部 Adapter、生产 UAT 或实体客户端验收已经完成。

## 被否决方案

- 将 OP 数据批量复制进动态表：产生双主、延迟和权限漂移。
- 让前端分别适配每个系统：解释语义分散，无法保证 REST、MCP 与自动化一致。
- 允许任意跨系统查询和写回：无法约束资源消耗、字段泄露和外部副作用。

## 安全与数据影响

所有读取继续绑定可信租户、主体 Scope 和来源应用服务；L3/L4 字段默认不进入通用
数据集投影。证据快照只保存业务决定所需最小字段，外部命令必须具备幂等、审计、
Outbox/Inbox 和稳定错误码，不得携带凭据或上游错误正文。
