4. 数据与安全边界

  • GaoQ MongoDB 只执行过 hello 只读探测：可写，但不是 Replica Set。容器与 /live 健康；严格 /ready 因此为 503，禁止放宽代码绕过。
  • 算薪 MongoDB/Redis 与 GaoQ Redis 均未发布主机端口，部署时未重启或重建数据库。
  • MASTER_DATA_SYNC_ENABLED=false；正式 OAuth 与联调完成前不得开启。
  • 服务客户端注册表仅补充原客户端的当前 ERP allowedResources；身份、Scope、角色、部门、凭据摘要与有效期未改。
  • 运行目录内的 pre-...-20260808 文件是敏感回滚备份，禁止提交、转发或打印。
