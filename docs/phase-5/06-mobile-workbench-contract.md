# Phase 5 移动工作台契约

## 范围

当前切片提供 `/mobile` H5 工作台、审批待办、审批详情与追加式时间线、R1 决策/转交/加签、限期委托管理和模板驱动的审批发起，首页摘要、知识与个人中心保留入口。审批能力只复用既有 REST 与 `ApprovalApplicationService` 权限投影；移动端不实现业务规则，不新增绕过 REST 的内部接口。知识任务和平台小程序容器属于后续增量，未完成前不得宣称移动端业务闭环验收。

## 身份与数据安全

- 身份只使用 ERP HttpOnly 会话；前端不接收、不选择、不持久化 tenantId、角色或 Scope。
- 请求必须 `credentials=include`、`cache=no-store`，页面卸载时中止；禁止把审批、员工、薪酬或令牌写入 localStorage、sessionStorage、IndexedDB、Service Worker Cache 或 URL。
- API 响应在渲染前执行固定字段、枚举、ULID、数量与长度校验；异常响应统一失败关闭。
- 审批详情由服务端按主体权限投影；L3/L4 字段无授权时只返回脱敏占位，前端不推断权限、不尝试还原。
- R1 决策携带服务端版本和幂等键；结果不确定时只允许复用原主体、动作、版本与幂等键重试，并阻止交叉执行其他任务动作。R2 决策在移动工作台保持只读，必须走 ERP Passkey 强认证。
- R1 转交/加签仅在可信身份摘要包含对应细粒度 Scope 时呈现，携带强版本与独立幂等键；R2 不渲染普通操作入口。转交来源固定为当前可信主体，加签目标由服务端复核当前会签节点和同租户有效主体。
- 本人委托只读取 `/api/approvals/delegations/mine`，创建与撤销复用现有 R1 REST、应用服务、Outbox 和审计；MCP 继续只开放 `erp://approval/delegations/mine` Resource，不注册授权写 Tool。
- 发起只读取 `GET /api/approvals/templates/published` 的已发布最小投影，再调用 `POST /api/approvals/instances` 与 `/submit`；不接受客户端 tenantId、流程节点或审批人解析器。
- PC 与 H5 复用同一套模板字段白名单校验。弱网导致创建结果不确定时保留原始正文和创建幂等键；创建成功但提交失败时保留实例版本和提交幂等键。所有可恢复状态仅存在当前页面内存。
- 发起、决策、转交、加签、委托创建和撤销的待重试状态绑定可信 actorId；登录主体变化即卸载并清空旧主体的业务正文、版本和幂等键。

## 体验与无障碍

- 手机 `<768px` 为单列卡片与底部四入口导航；平板/桌面保持最大 720px 阅读宽度。
- 交互热区不小于 48px，使用语义化 header/main/nav/section、可见焦点、`aria-current` 和状态文本。
- 支持安全区、动态视口与 `prefers-reduced-motion`；不以颜色作为唯一状态表达。
- 弱网/未登录/非法响应统一展示可恢复错误，不展示服务端异常正文。

## 验收门禁

- 375px、768px 与桌面断点无横向溢出，键盘与读屏主导航可用。
- 未登录、403、500、超时、Abort、空列表和 200 条上限测试通过；模板非法字段、必填项、金额整数分、日期、选项白名单与文件引用边界测试通过。
- 浏览器存储、Cache Storage、URL 与日志中不存在业务正文、Token 或租户标识。
- 375px、768px、桌面断点及屏幕键盘下完成模板选择、动态表单、弱网创建重试、草稿提交重试、R1 转交/加签、委托创建/撤销和成功返回待办列表的实体 UAT。
- 前端 lint、typecheck、测试和 Next.js production build 通过；真实钉钉/飞书容器、目标 SSO 与实体手机 UAT 完成前保持“外部验收待完成”。
