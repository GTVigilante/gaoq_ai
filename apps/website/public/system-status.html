GaoQ Operating System / Delivery Brief

一套连接人、流程、数据与 AI 的企业运营系统。

GaoQ-OS 是告趣 ERP 的统一技术与业务底座，覆盖组织人事、审批、招聘入职、培训关怀、薪酬协同、资金对账、经营分析和标准 MCP 服务。

Phase 0–6 计划内代码已交付 首发版已上线 生产联调与业务验收进行中

01 / 当前结论

代码交付完成，不等于整个项目已经完成。

当前仓库规划内的业务代码、部署编排、迁移工具、质量门禁和 MCP 服务均已交付。公共 CI、自动化测试和临时 Kubernetes 运行自证已经通过；剩余工作集中在真实企业系统接入、生产等价验证、数据迁移、业务 UAT 与正式切换。

02 / 系统能力

统一业务规则，多入口共享同一套可信服务。

IDENTITY

身份与组织主数据

可信租户上下文、员工与部门主数据、角色权限、OAuth 2.1 与多平台身份接入边界。

WORKFLOW

审批与协同

审批模板、实例、任务、通知、超时升级与完整审计，支持 Web、移动端和 AI 入口。

TALENT

招聘与人才全周期

职位、候选人、简历智能处理、入职、任职、离职、校友与服务触点的统一视图。

PEOPLE OPS

培训、关怀与人事运营

知识培训、员工关怀、服务跟踪和业务留痕，关键动作均受权限与审计控制。

PAY & FINANCE

薪酬协同与资金对账

ERP 负责统一身份组织，专业算薪作为工资事实源；发放、税务文件与对账按受控边界协同。

INSIGHT

经营分析与内容运营

管理视图、受控指标、双语官网 CMS、招聘门户及线索入口，统一来源与发布流程。

MCP

AI CONNECTION STANDARD

为各类 AI 提供标准、受控、可审计的连接层。

MCP 与业务模块同步交付，复用 ERP 应用服务，不允许 AI 直接访问数据库或绕过权限。服务支持标准发现与 OAuth 2.1，按租户、主体、角色、部门范围和最小权限控制访问。

标准 Tool / Resource / Prompt OAuth 2.1 与服务身份 可信租户与最小权限 只读优先、危险动作禁入 审计、幂等与协议测试 官方 MCP SDK 握手验证

MANAGEMENT VERDICT

当前可以说“代码已交付”，还不能说“ERP 项目最终完成”。

准确口径：计划内代码交付完成，公共 CI、自动化测试、临时 Kubernetes 自证与首发版上线已完成；生产环境真实联调、现场验收和最终切换尚未完成。联调和 UAT 期间如发现接口差异，仍需按变更流程修复并回归验证。
